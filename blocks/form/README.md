# form

Custom **form** block. Purpose: Contact form authored as a table of field definitions.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional header row, then one row per field: Type | Name | Label | Required | Options | Placeholder | Layout; optional trailing settings rows: Submit URL | url, Success message | text, Error message | text.
