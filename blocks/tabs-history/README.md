# tabs-history

Custom **tabs** block. Purpose: Company history timeline as period tabs.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: One row per period: tab label | text (optional title heading, subtitle heading, paragraphs or list) | image (optional second image = mobile crop).
