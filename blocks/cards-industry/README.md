Custom **cards** block. Purpose: Industry or category navigation tiles.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Cell 1: image. Cell 2: H3 title, optional description paragraph, link to the detail page (makes the whole tile clickable).
