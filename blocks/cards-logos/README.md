# cards-logos

Custom **cards** block. Purpose: Brand or partner logo strip.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Cell 1: logo image (alt = brand name). Cell 2 (optional): brand name, kept as a visually hidden label when a logo is present.
